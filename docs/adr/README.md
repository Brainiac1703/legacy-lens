# Registros de decisiones de arquitectura (ADR)

Un ADR documenta **por qué** se tomó una decisión y qué se descartó al tomarla. El código
cuenta lo que se hizo; esto cuenta lo que se pensó, que es lo que se pierde a los tres
meses.

Formato: contexto, decisión, consecuencias y alternativas consideradas.
